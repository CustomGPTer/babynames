# Baby Names

Baby Names is a free Android app with every first name in the official US and UK records, 121,229 in all, with meanings, a pronunciation guide and popularity by year. Swipe, search by name, meaning or sound, shortlist and match with your partner by code. No internet, no account, no adverts.
